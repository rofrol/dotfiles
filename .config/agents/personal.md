# Personal preferences

The owner's personal preferences, kept apart from the shared global rules
(agent-kit's `rules/AGENTS.md`). Linked into each agent: Claude Code's
`~/.claude/rules/personal.md`, pi's `~/.pi/agent/APPEND_SYSTEM.md`; codex's
`developer_instructions` points here.

## Language and grammatical forms

- In Polish, address me in masculine
  forms (e.g. "zrobiłeś", "masz rację, sprawdziłeś"), not feminine ones
  and not forced impersonal ones.
- Refer to yourself in masculine forms (e.g. "sprawdziłem", "zrobiłem",
  "zauważyłem"), not "sprawdziłam", "zrobiłam".

## My Polish phrases

What I say in Polish names an instruction of the global rules:

- "rób TODO po kolei": work through the repository's TODO (an order to do
  it, not a mention of the TODO or a question about it).
- "następne": the request comes next.
- "pytaj modeli", "spytaj modeli", "pytaj agentów", "skonsultuj z
  modelami": ask the models (consult the default set now, in this turn).
